Windows Font Access & MSIX Flexible Virtualization

FontShelf uses Windows 11 MSIX Flexible Virtualization strictly limited to %LOCALAPPDATA%\Microsoft\Windows\Fonts and HKCU\Software\Microsoft\Windows NT\CurrentVersion\Fonts. All app settings, preferences, caches, and visual search indexes remain virtualized inside the MSIX container. FontShelf never modifies HKLM, %WINDIR%\Fonts, font substitution/linking keys, system directories, services, drivers, scheduled tasks, or ACLs. TargetDeviceFamily MinVersion="10.0.22000.0" (Windows 11+) eliminates any Windows 10 broad virtualization disable fallback. All font install/removal operations happen strictly after direct user action.

Validation, Conflict Handling, Transactions & 1-Click Remove All

Supported Formats: .ttf, .otf, .ttc, .otc (validated before install: regular non-symlink file, extension & 1B–50MB size gate, SFNT/TTC magic bytes, ttf-parser face/units_per_em/glyph_count validation, sanitized path boundary, SHA-256 digest).

Duplicate & Non-FontShelf Protection: Identical SHA-256 files are idempotently skipped; duplicate filenames with new hashes use collision-safe {stem}-{hash7}.{ext} with exclusive creation (create_new(true)); conflicting HKCU\...\Fonts names and non-FontShelf removals prompt explicit user confirmation before any write or removal.

Install/Remove Sequence & Rollback: Installs write exclusively, register HKCU, call AddFontResourceW (checking return > 0, rolling back on failure), broadcast WM_FONTCHANGE, and record into the persistent install ledger. Removals call RemoveFontResourceW + WM_FONTCHANGE, send the file to the Windows Recycle Bin first (and stage a copy in virtualized Removed storage for one-click restore), roll back cleanly via AddFontResourceW + WM_FONTCHANGE (leaving HKCU and ledger intact) if locked by another process, and delete matching HKCU values only after file removal succeeds. Dedicated uninstall-all in the FontShelf tab (2-step confirmation in the right panel) removes exclusively FontShelf-tracked per-user fonts while keeping originals in the Recycle Bin and virtualized restore copies in the Removed tab.

After Uninstall & Font Removal Instructions

Uninstalling FontShelf automatically deletes the MSIX package and all virtualized settings/caches while leaving user-installed fonts intact so existing documents keep working. To remove any font after FontShelf has been uninstalled: open Windows Settings → Personalization → Fonts, search for the font, and click Uninstall (or manually remove the file from %LOCALAPPDATA%\Microsoft\Windows\Fonts and matching REG_SZ value from HKCU\Software\Microsoft\Windows NT\CurrentVersion\Fonts).
